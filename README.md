English Trainer — это веб-приложение для изучения английских слов и тренировки словарного запаса.

Проект помогает пользователю:
- изучать новые английские слова
- повторять выученный материал
- тренировать перевод через карточки и упражнения

Цель проекта
Разработка образовательного веб-сервиса, который помогает пользователям изучать иностранный язык в интерактивной форме.

 Функциональность
- Просмотр словаря
- Добавление новых слов
- Редактирование слов
- Тренировка (слово → перевод)
- Вывод списка карточек

Страницы проекта
- Главная страница
- Список слов (вывод данных)
- Добавление слова (форма)
- Редактирование слова (форма)
- Тренировка (квиз)

Формы
1. Добавление слова
- английское слово
- перевод
- проверка на пустые значения

2. Редактирование слова
- изменение слова
- изменение перевода
- валидация данных

Валидация форм

Все формы проверяют:
- пустые поля
- корректность ввода
- вывод понятных ошибок пользователю

Технологии
- Python 3.12
- Django
- HTML (Django Templates)
- CSS / Bootstrap 
- JSON или SQLite
